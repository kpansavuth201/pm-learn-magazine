Baseline
Definition An approved reference point used for comparison against actual results.
Components Scope baseline (WBS + scope statement); schedule baseline (approved timeline); cost baseline (time-phased budget).
Related scope baseline, cost baseline, planned value
Example The status report compares actual progress against the approved baselines — scope is on track, schedule shows a 2.5-day variance, cost is 4% favorable.
Variance
Definition The difference between planned and actual performance.
Components Schedule variance (timing gaps); cost variance (budget gaps); scope variance (deliverable gaps); trend direction.
Related baseline, cost variance, earned value
Example The 2.5-day schedule variance on environment setup is a measurable gap between where the plan said the team would be and where they actually are.
Performance Measurement
Definition The process of tracking and evaluating project progress.
Components Defining metrics; collecting data; comparing against baselines; reporting results; recommending corrective actions.
Related earned value, planned value, actual cost
Example Hina's report tracks planned value (¥9.6M), earned value (¥8.9M), and actual cost (¥8.5M) — three data points that together reveal both schedule lag and cost efficiency.
Control Account
Definition A management control point for scope, schedule, and cost integration.
Components Assigned to a WBS element; has its own budget and schedule; owned by one person; performance measured independently.
Related WBS, work package, cost baseline
Example The rendering module has its own control account, making it easy to see that the crash recovery is the source of the schedule variance — without that isolation, the problem would be hidden in aggregate numbers.
Work Authorization
Definition A formal approval to begin work on a specific project activity.
Components Identifies the activity or work package; specifies start conditions; assigns resources; links to the schedule and budget.
Related work package, scope baseline, schedule
Example The spatial mapping module received formal work authorization before development began — ensuring the team had approved scope, budget, and schedule before committing resources.
